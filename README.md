# 🤖 Sweekar's AI-Powered Portfolio

What if your portfolio *talked back*?

Welcome to a futuristic developer portfolio, powered by a custom-built conversational AI assistant. Instead of scrolling through static project cards, you can now **chat with me, ask questions, explore my work, or even talk to my AI twin.**

---

## 🚀 Live Features

- 🎙️ **AI Assistant** – A real-time, LLM-powered agent that introduces me and guides you through my work.
- 🧠 **Voice + Text Chat** – Seamless multi-modal interaction (voice input, text fallback).
- 🗂️ **Project Walkthroughs** – Ask about any project, and the assistant will give detailed responses + previews.
- 🌐 **Cinematic Landing Page** – Scroll-triggered animations, smooth transitions, and futuristic UI.
- 📱 **Responsive Design** – Fully optimized for desktop and mobile (AI behaves contextually).
- 🔧 **Custom Stack** – No drag-and-drop builders; everything built from scratch with ❤️

---

## ⚙️ Tech Stack

- **Frontend**: Tailwind CSS,JS, HTML5
- **Backend**: Python + Flask +Faster Whispher
- **AI**: LLM integration via OpenRouter with custom tool calling 
- **Voice**: Web Speech API for voice input + text-to-speech 
- **Socket.IO**: Real-time chat and assistant state sync

---

## 🎯 Why I Built This

Most portfolios are static, cold, and outdated.

I wanted mine to feel like a **living product**—a place where people can *experience* how I think, build, and solve problems.  
Whether you're a recruiter, teammate, or investor, you deserve more than just a bullet list of skills.  
You deserve a demo of my brain in motion.
