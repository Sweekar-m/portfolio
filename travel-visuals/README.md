# Sweekar M. — Travel & Adventure Photography

A responsive, single-page portfolio for travel, landscape, and motorcycle photography. Built with HTML, CSS, and vanilla JavaScript, with no build step or dependencies.

## Preview locally
Open `index.html` in your browser.

## Personalize before sharing
1. Replace the sample Unsplash image URLs in `index.html` with paths to your own images (recommended: `assets/your-photo.jpg`).
2. Add the photos to an `assets/` folder in this project.
3. Update the contact email from `hello@example.com` to your professional email.
4. Edit the About section and image captions to match your real work.

**Important:** Sample images are only layout placeholders. They are not photographs taken by Sweekar and should not be presented as his work.

## Deploy
This folder can be published using GitHub Pages. In the repository settings, select **Pages**, choose **Deploy from a branch**, and select the branch containing the project and the `/ (root)` folder. If you want this nested folder to be the site root, move the files to the repository root or configure a dedicated deployment workflow.

## Features
- Responsive layout
- Filterable photography gallery
- Click-to-enlarge lightbox with Escape-to-close
- Accessible labels and reduced-motion support
- Sections for services, background, and assignment inquiries
